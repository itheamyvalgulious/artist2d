# roll + slash2 独立复核清单（供最终验收子代理使用）

被审对象：`roll-slash-refine` 的交付物。
判定：逐条给 PASS/FAIL + 证据（文件路径、坐标、像素数、截图路径）。任一硬项 FAIL 即整体 FAIL。
必须自己重新取证，不得采信执行代理的完成声明；审核期间产物目录必须已冻结并附 sha256 清单，若审核中发现目录变动，本轮结论作废。

## A. 范围锁定（硬）
- A1 只改了 `roll` 与 `slash2`；`slash1/slash3/idle/run/jump/in_air/shoot1-3/block` 未被改写或降级（给出前后对比证据）。
- A2 选择记录在 `work/roll_slash/LOG.md` 且未中途更换动作、未扩大到第三个动作。

## B. 硬规定（硬）
- B1 交付帧无任何 2D 叠加/合成补件：武器、眼睛、枪套、刀鞘均整张由绘图模型产出。检查生成脚本与像素证据（例如武器区域是否存在纯色贴片、重复 sprite、非模型笔触的硬边）。
- B2 交付的 2D 画面无程序化生成的部件。3D 木偶上的配件（刀/鞘/枪/枪套）只作为参考渲染输入，不得进入交付帧。
- B3 100% 多模态检验：roll 与 slash2 各 8 帧 × (512、64) 全部被独立审核看过；含 8× 放大、跨帧并排、衔接锚点、循环/首尾。
- B4 审核结论 0 blocker、0 major；minor 逐条列出并判断是否影响可用。审核者必须是 `dawnfm/deepseek-v4.1-flash-1017` variant high 的独立新会话。

## C. 提示词纪律（硬）
- C1 存在唯一的固定生成模板 `work/roll_slash/prompt_generate_fixed.md`，逐帧/逐板使用同一份，无按动作或按帧分叉的变体。
- C2 该模板不含画面级指令：`arc`、`wind-up`、`raised`、`45`、`behind her`、`over her head`、`this image`、`in this panel` 等动作/构图词（用 grep 复核）。
- C3 代码路径里 `action_extra` / `_SLASH_ARC` / `gear_rules()` 不再进入生图 prompt（grep + 运行证据）。
- C4 唯一的现场定制 prompt 只用于「修参考图/动作板」，且有完整记录（输入图、缺陷描述、prompt、输出、是否修好）。逐帧成片生成中不存在定制 prompt。

## D. 立绘提示词（硬）
- D1 `design_sheet_prompt_v2.md` 只描述角色，不含动作/构图/相机指令。
- D2 身体部分严格按顺序覆盖：头 → 手臂 → 背部 → 胸部 → 小腹 → 大腿 → 小腿 → 脚；每处写明款式/颜色/材质/长度/贴身程度，或明确写"无（裸露）"；跨部位衣物在每个相关部位都写了覆盖关系。
- D3 配件部分每件都有：名称、详细样式（尺寸比例/形状/颜色/材质/装饰）、佩戴部位（身体部位+左右+前后）、状态。
- D4 措辞具体到可画，不含"美丽/帅气/好看"这类空话。
- D5 立绘实际产出 `output/character/agent_v2/design_sheet_v2.png`，含全身 + 每件配件独立零件图 + 佩戴关系示意。

## E. 三个实验（逐项给结论）
- E1 纹理化人体木偶：记录了模型来源与许可证、导入方式、KayKit 动作重定向可行性、roll/slash2 各 8 帧渲染图、与旧木偶同姿势并排对比；若失败，给出失败原因与已回退证据，不得含糊。
- E2 失败图改图：至少一次真实使用，记录输入图/缺陷描述/prompt/输出/结果；确认未越界到逐帧成片。
- E3 标定与对齐：头、双手、剑、双脚、肚子五类坐标；标记-复核循环 ≤4 轮且有每轮坐标；以肚子为锚对齐；全组统一缩放（非逐帧 bbox）；64px 肚子锚点标准差 ≤1px；四边留白 ≥8px；512 与 64 锚点一致。给出统计量与带标记对照图。
